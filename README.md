# Iudjin Shop

Исходный код статической витрины интернет-магазина. В проект входят адаптивная страница на русском, английском и румынском языках, изображения-заглушки, корзина и демонстрационная форма оформления.

## Публикация на GitHub Pages

1. Создай репозиторий на GitHub и загрузи в него все файлы из этого архива, сохранив структуру папок.
2. Открой **Settings → Pages**.
3. В разделе **Build and deployment** выбери источник **GitHub Actions**.
4. После отправки файлов открой вкладку **Actions** и дождись завершения процесса **Deploy to GitHub Pages**.
5. GitHub покажет ссылку на опубликованный сайт в разделе **Settings → Pages**. Дальнейшие изменения будут публиковаться после каждого push в ветку `main`.

Рабочий процесс публикации уже находится в `.github/workflows/deploy-pages.yml` и размещает папку `site`.

## Структура

- `site/index.html` — страница магазина и её интерактивность.
- `site/assets/` — обложка и четыре изображения-заглушки.
- `.github/workflows/deploy-pages.yml` — автоматическая публикация через GitHub Pages.
